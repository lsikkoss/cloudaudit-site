Questions

Before you book

What access do you need?

One read-only IAM role in your account, created from a template we send. It can view costs and configuration but cannot change, create, or delete anything, and it cannot read your files or databases. You remove it when the audit ends.

Will you change anything in my account?

No. The audit is read-only. If you want help applying the fixes, that's a separate Implementation project with its own scoped access that you approve.

How is my data handled?

We sign an NDA on request, keep exported billing data only for the audit, and delete it within 30 days of delivery.

We only spend $1,500 a month. Is it worth it?

The Starter Scan is built for that size. Below about $1,000 a month, the savings usually don't justify a paid audit, and we'll tell you so on the call.

Do you work with Azure or Google Cloud?

We focus on AWS today. Ask on the call if you run a mix.
